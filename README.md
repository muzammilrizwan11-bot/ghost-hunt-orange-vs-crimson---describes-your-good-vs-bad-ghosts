A unique take on the classic Ghost Hunt game, built with p5.js.

### 🎮 Gameplay
- **Orange Ghost = +1 point** — Catch it!
- **Red Demon = -2 points** — Avoid it!
- 30 seconds to get the highest score

### ✨ My Own Additions

**1. Own Art:**
- Deep space blue theme (26,26,46)
- Twinkling starfield background
- Custom ghost design (orange with smile)
- Original enemy: Crimson Demon with horns and red eyes

**2. Own Effects:**
- **Burst Effect:** 12-particle explosion when a ghost/demon is clicked
    - Yellow burst for ghost
    - Red burst for demon

**3. Own Sound (No files needed):**
- Ghost caught: High 880Hz happy chime (sine wave)
- Demon hit: Low 120Hz scary BOO! (sawtooth wave)
- Made with Web Audio API

**4. Own Font:**
- Courier New Bold for that arcade feel

### 🚀 How to Run
1. Go to https://editor.p5js.org
2. Create new sketch
3. Paste the code from `sketch.js`
4. Press Play!
